# Kişisel CV Projesi 💼🌐

## 🎯 Proje Hakkında
Bu proje, **benim kişisel CV’min HTML ve CSS kullanılarak oluşturulmuş dijital versiyonudur**.  
Amacı, **kariyer bilgilerimi, eğitim geçmişimi ve yeteneklerimi çevrimiçi olarak paylaşmak** ve GitHub Pages üzerinden erişilebilir hale getirmektir.  

---

## 🧩 Teknolojiler
- **HTML5** – Sayfa yapısı ve içerik  
- **CSS3** – Tasarım ve stil  
- **GitHub Pages** – Canlı yayın ve barındırma  

---

## 📂 Dizin Yapısı
- `index.html` – Ana sayfa ve CV içeriği  
- `style/` – CSS dosyaları ve stil dosyaları  
- `images/` – Profil fotoğrafı ve diğer görseller
